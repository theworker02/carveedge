# carveedge

Carve identifiers and edge tokens for idempotent workflows.

**Site:** https://theworker02.github.io/carveedge/

## Install / run

```bash
git clone https://github.com/theworker02/carveedge.git
cd carveedge
node src/cli.js
node --test
```
